## Goal

Every staging and production vhost sends the header baseline and the per-route CSP of `17` §14 — inside every
`location`, because nginx does not inherit `add_header` — and a header snapshot check per host and route class proves
it after each deploy.

## Legacy reference

- Header table `17` §14 (Mini App legacy artefacts, legacy `/api/*`, `/media/*`, `/call/*`, landing legacy files,
  SEO pages, API/hook/ARM hosts); baseline SEC-REQ-033; CSP SEC-REQ-030, SEC-REQ-031; CORS SEC-REQ-032.
- Legacy header still to be captured (Q-APP-016, `17` §16); framing in Telegram Web (Q-SEC-012).
- Existing local snippet `infra/local/nginx/snippets/security-headers.conf` and the convention note of
  `docs/ai/reports/phase-3-notes.md` §A (headers repeated per location).

## Implementation

1. `infra/{staging,production}/nginx/snippets/headers-baseline.conf`: HSTS (`max-age=31536000; includeSubDomains`
   — preload only after a separate decision), `X-Content-Type-Options: nosniff`, `Referrer-Policy:
   strict-origin-when-cross-origin`, `Permissions-Policy` (geolocation only on the Mini App origin).
2. Route-class snippets from `17` §14: legacy Mini App (`include legacy-csp-miniapp.conf` generated by KV-INF-010);
   legacy `/api/*` (`default-src 'none'; frame-ancestors 'none'`, `Cache-Control` left to Laravel); `/call/*`
   (`default-src 'none'; style-src 'unsafe-inline'`, `Referrer-Policy: no-referrer`, `X-Robots-Tag: noindex`); landing
   legacy files (the legacy landing header with its hashes from KV-INF-010); `api.*`, `hook.*` (`default-src 'none';
   frame-ancestors 'none'`); ARM (nonce CSP from the app, `X-Robots-Tag: noindex`).
3. Include the baseline and the class snippet in **every** `location` block of every vhost (lint script
   `infra/server/check-headers-includes.sh` fails when a location lacks them).
4. Header snapshot check `infra/server/header-snapshot.sh <env>`: curls one URL per host × route class and compares the
   relevant headers with `infra/<env>/headers.expected` (names and values without per-deploy nonces); run by the deploy
   smoke step (KV-INF-023).
5. CSP reports: confirm `/api/csp-report` is reachable on both legacy hosts and rate-limited (backend route, RES-015);
   alert on spikes (KV-INF-025).

## Files

- `infra/staging/nginx/snippets/*.conf`, `infra/production/nginx/snippets/*.conf` (new or changed)
- `infra/server/check-headers-includes.sh`, `infra/server/header-snapshot.sh`, `infra/{staging,production}/headers.expected` (new)

## API contract

Response headers only; no endpoint changes.

## Business rules

None; the legacy client is served unchanged, so the legacy CSP can be no stricter than its own inline code allows
(KV-INF-010).

## Acceptance criteria

- The snapshot check passes for every host and route class on staging after each deploy.
- No location in any vhost lacks the baseline include (lint green).
- A headless run of the parity scenarios on staging produces zero CSP reports (`18` §5.1 Mini App parity row).
- `api.*`, `hook.*`, `arm.*` and legacy `/api/*` send `frame-ancestors 'none'`.

## Edge cases

- Next.js (SEO pages, later the new Mini App) sets its own CSP with nonces; nginx must not add a second CSP header on
  those locations (two CSP headers intersect and break pages).
- HSTS on `*.staging.homi.uz` with `includeSubDomains` affects every staging name — acceptable, all are HTTPS.
- `frame-ancestors` for the Mini App origin depends on Q-SEC-012; until answered, follow the captured legacy header.

## Definition of done

Snapshot and lint green on staging and production vhosts, zero CSP reports in the R2 parity run, `17` §14 rows marked
done in the production notes, reviewed by the `security-reviewer` agent's checklist.
