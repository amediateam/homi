## Gotchas learned this session
- `boost:add-skill` needs a GitHub token after ~60 unauthenticated calls: `BOOST_GITHUB_TOKEN="$(gh auth token)" php artisan boost:add-skill …` (config key `boost.github.token`).
- Boost syncs only skills listed in `boost.json` `skills`, and third-party *package* skills only for packages in `boost.json` `packages` (Scramble had to be added by hand; the discovery prompt is interactive-only).
- Vendored skill names can collide with official Boost skills (KI-16); `vercel-labs` skills are written twice (dir name vs frontmatter name).
- Boost agent dirs for Cursor/Junie/Codex/Grok are generated under `backend/` (gitignored) and, with our path overrides, `.agents/skills` + `.grok/skills` at the root (gitignored).
