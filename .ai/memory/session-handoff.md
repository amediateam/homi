## Gotchas learned this session
- Run the e2e suite locally as `env -u CI pnpm exec playwright test --project=miniapp --workers=1` from `frontend/`: with `CI=1` the run drops `NODE_EXTRA_CA_CERTS` (mkcert) and every sign-in answers `502`.
- Every spec signs in as the one stub user, and the API allows it 120 requests per minute (`AppServiceProvider::configureRateLimiting`): a full local run (85 tests) can fail late tests at `data-session="booting"` or while waiting for `"ready"`. Check the ` 429 ` lines of the API access log (the `access_log` of `infra/local/nginx/api.homi.conf`), wait a minute and rerun the file alone. CI is unaffected: `frontend-e2e.yml` starts the API with `CACHE_STORE=array` under PHP's built-in server (AM-61).
- `notFound()` thrown outside `<Suspense>` serves Next.js's `<html id="__next_error__">` shell without the head scripts (no boot script, no SDK tag); throw it from an async child under `<Suspense>` (AM-59). The client head then has two `noindex` tags: locate them with `.first()`.
- Next.js 16.4 moves no focus on a navigation, and the route announcer speaks only when the title changes (the title is the constant brand name): a screen that replaces the route focuses its heading or its one action (AM-60).
- The root font is 15 px, so a Tailwind rem utility is 6.25 % small (`h-11` = 41.25 px): spell the legacy pixels (`h-[44px]`, AM-62).
- A live region inside a `<button>` is not reliably announced (its children are presentational), and `disabled` on the focused control drops the focus: put the status beside the button and use `aria-disabled`.
- The `react-hooks/immutability` lint rule rejects writing module state inside a component closure: write through a module-level helper.
- From earlier: nginx answers 500 "Operation not permitted" under `~/Documents` after a reload — `make dev-nginx-restart` from Terminal (KI-31); `gh pr merge --delete-branch` on the base of a stacked PR closes the upper PR (retarget it first); the guard hook denies any shell write to `.env*`; a `make … | tail` over `services.sh start|restart` never returns; nginx config for the Next hosts is in `infra/local/nginx/snippets/`; `cacheComponents` needs `await io()` before `crypto.randomUUID()`/`Date.now()`; e2e locators need `.filter({ visible: true })`; Vitest has no `globals` (call `cleanup()`); `AbortSignal.timeout` ignores fake timers; `pnpm install --offline` fails the supply-chain check; a `brew upgrade` can break `node` for minutes (wait); zsh: no loop variable named `path`, no bare `echo ===`.
